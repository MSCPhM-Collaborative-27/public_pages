5Quick reference

Most of this has a VS Code button equivalent — see §3. This table is for the terminal: useful once you're comfortable with it, or when troubleshooting.

CommandWhat it does
git checkout -b yourname/topicStart a new branch off main
git push -u origin yourname/topicPush it and link it to GitHub
git pull origin mainPull main's latest changes into your current branch
git statusSee what's changed, and which branch you're on
git add <file>Stage a change
git commitSave the staged changes
git stash / git stash popSet aside uncommitted changes / bring them back
git switch -c yourname/topicMove uncommitted work off main onto a new branch
git reset --soft HEAD~1Undo the last (unpushed) commit, keep the changes staged
