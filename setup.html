2Setup

Do you need this page?

Only if you'll be contributing regularly. Just reading, or making a one-off small fix, needs nothing installed — see the paths in §1.2.

2.1Install & open VS Code

VS Code is a free text editor. The rest of this guide assumes you're using it. You don't need it to read notes on GitHub — only to edit them and run Git.

  1. Download and install it from code.visualstudio.com.
  2. Open it. Go to File → Open Folder… and pick or create a folder to work in. VS Code calls this your workspace.
  3. Open a terminal inside VS Code: Terminal → New Terminal. A panel opens at the bottom of the window — this is where every command in this guide gets typed. Click inside that panel before typing anything.

2.2Connect Git & GitHub

VS Code edits files. Git is the separate program that tracks versions and talks to GitHub. Install it first if you don't have it:

  • Windows: install Git for Windows — the default options are fine.
  • Mac: type git --version into Terminal once; macOS offers to install it automatically if it's missing.

In the terminal panel you opened above, tell Git who you are — it stamps every change with this:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global pull.rebase false

Use the same email you were whitelisted with. The third line tells git pull to merge rather than rebase when needed — the simpler default for this workflow.

Then sign in to GitHub from inside VS Code: click the Accounts icon in the bottom-left corner → Sign in with GitHub → follow the browser prompt. This lets VS Code push, pull, and open PRs on your behalf without re-entering credentials every time.

2.3Clone the repository

Cloning means downloading a full copy of the repository — including its history — onto your computer. After that, you stay in sync with two commands: pull brings down other people's changes, push sends up yours.

  1. Confirm you've actually been added to the repo (§1.5) — until then, the URL below will 404 for you.
  2. In VS Code: View → Command Palette → Git: Clone, paste the repository URL, and choose a local folder. The repository URL is on GitHub, behind the green Code button: 
    https://github.com/MSCPhM-Collaborative-27/courses_and_notesharing.git

    Prefer the terminal? Same thing, typed into the panel from §2.1:

    git clone https://github.com/MSCPhM-Collaborative-27/courses_and_notesharing.git
  3. Open the cloned folder in VS Code (File → Open Folder…). You now have every module and every note on your machine, ready to branch.
